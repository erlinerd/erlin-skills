# Changelog

## 0.0.1

First public release.

- 27 skills in four buckets: `workflow` (engineering discipline & reviews), `apple` (full App Store shipping chain), `web` (web motion & marketing assets), `garden` (course authoring & personal knowledge)
- Machine-validated catalog: contract tests keep the routing table, flow map, plugin manifest, docs tree, and invocation policies in sync with the skill directories
- Dual install: Claude Code plugin marketplace, or clone + `scripts/link-skills.sh` (pure bash, no runtime)
- Bilingual trigger descriptions (EN + 中文) on the nine core skills
- Human docs for every skill under `docs/<bucket>/<skill>.md`
