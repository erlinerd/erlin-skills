## What it does

用户个人知识库——习惯、信息、偏好，以编号条目存于 ~/.me/（XDG 风格用户目录）。用户说"录入/记一下/保存 xx""me 里有什么""查一下我的习惯/偏好""把这个记到 me"、输入 /me 时使用；发现可复用的用户习惯或偏好时主动询问要不要录入。

## When to reach for it

录入、查询或盘点用户个人习惯/偏好（me 库）时使用：用户说“录入/记一下/保存 xx”“me 里有什么”“查一下我的习惯/偏好”“把这个记到 me”、输入 /me，或说“探查/搜寻我的习惯”“me 里该记什么”即触发；对话中出现尚未录入的可复用习惯、偏好或事实信息时，也主动询问“要不要录入 xx 到 me”，无需点名本技能。

## Common questions

- **和 GLOSSARY.md 什么区别？**

  GLOSSARY 是项目领域语言；profile 是跨项目跟着人走的个人事实。

- **怎么录入？**

  说"记一下/录入"，条目编号存 ~/.me/，说"me 里有什么"可查。

## It's working if

- 说"记一下 xx"后，条目以编号形式落进 ~/.me/，"me 里有什么"能查到它。
- 查询命中的是具体条目内容（习惯/偏好/事实），不是模糊复述。
- 对话中出现可复用习惯时被主动问"要不要录入"，且单次事件不被误沉淀。
