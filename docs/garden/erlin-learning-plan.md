## What it does

把一个项目、代码库或文档集安排成一份可执行的系统学习计划——在项目 `.erlin/course/` 生成首页源码/内容地图、计划页、记录页和带导览的工作纸。用户提到"学习计划/安排学习/怎么学这个项目/把 XX 弄成学习专题/系统读透 XX/建学习库/写篇章工作纸"时使用——即使没提 skill 名。

## When to reach for it

把项目、代码库或文档集安排成可执行的学习计划，在 .erlin/course/ 生成首页地图、计划页、记录页与篇章工作纸时使用；提及"学习计划/怎么学这个项目/建学习库/写篇章工作纸"即触发。产出可教学的课程/课件用 erlin-course（制作模式）。

## Common questions

- **产出什么结构？**

  .erlin/course/ 下：首页源码/内容地图、计划页、记录页、N 篇带导览的工作纸。

## It's working if

- .erlin/course/ 下生成完整结构：首页源码/内容地图、计划页、记录页、带导览的工作纸。
- 每篇工作纸有导览（先读什么、带着什么问题读），不是裸链接列表。
- 计划可执行：按计划页推进即可系统读完，不用再自行排顺序。
