## What it does

课程制作的引导流程——逆向设计 (UbD)：先定学习目标和评估、后写正文，叠加 Bloom 可观察动词、Gagné 九事件骨架、Mayer 排版规则与密度基线。被要求"做一门课 / 写一节课 / 设计课时 / 写课件 / 润色课件"时使用——即使没明说 skill 名；拿到题目就堆正文是本技能要拦的第一件事。与 erlin-course-review 配套：交付前必过那个。

## When to reach for it

从零设计课程、写单节课时、搭课时结构、把主题变成可教学的内容，或对已有课件做结构性修改/润色时使用。只评不写时用 erlin-course-review；只管课件承载代码的实现时用 erlin-dev-standards。

## Common questions

- **逆向设计是什么顺序？**

  学习目标（Bloom 可观察动词）→ 评估（怎么算学会）→ 正文。评估先于内容。

- **写完就能用吗？**

  必须过 erlin-course-review，用户明确免审才可跳。

## It's working if

- 设计顺序正确：先有 Bloom 可观察动词写的目标、再有评估方式，最后才动正文。
- 课件结构带 Gagné 九事件骨架，排版符合 Mayer 规则与密度基线。
- 交付前过了 erlin-course-review（或用户明确免审），不是写完即交。
