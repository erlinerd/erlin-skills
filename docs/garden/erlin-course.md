## What it does

课程制作与评审合一。制作模式走逆向设计（UbD）：画像 → Bloom 可观察动词目标 → 评估先于正文 → Gagné 九事件骨架 → 正文 → 必过评审。评审模式按 QM 8 大类、OSCQR、Bloom 修订版、逆向设计对齐、Gagné、Mayer 五套量表给三档判决（过/有条件过/不过）+ P0/P1/P2 分级清单。前身是 erlin-course-create 与 erlin-course-review，已合并。

## When to reach for it

被要求"做一门课/写一节课/设计课时/写课件/润色课件"（制作模式）或"评课/审课/课件验收/上线前把关/课件自审"（评审模式）时使用。只管课件承载代码的实现时用 erlin-dev-standards；把项目/代码库排成个人系统学习计划用 erlin-learning-plan。

## Common questions

- **两种模式怎么切？**

  按请求动词判定：做/写/设计/润色 → 制作；评/审/验收/自审 → 评审。"写完帮我审"→ 先制作后评审串行。拿不准就问一句。

- **评审会顺手改稿吗？**

  不会。评审不改稿，发现问题给三要素（位置、违反条款、修法）；要改切制作模式。

## It's working if

- 制作：交付序列完整（假设清单 → 目标 → 评估对齐表 → 骨架 → 正文 → 自审），拿不到题目的直接开写正文。
- 评审：verdict 三档 + 每条问题三要素齐全，P0 四类（目标缺失/不可验证动词/不对齐/练习无反馈）从不降级。
- 交付前自审 P0 清零（或用户明确免审）。
