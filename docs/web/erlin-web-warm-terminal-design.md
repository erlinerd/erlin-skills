## What it does

Apply or fully replicate the "Warm Terminal" style — warm dark dev-tool terminal aesthetic. Use when the user names this style, asks to replicate/复刻 the personOS landing page, wants a dark landing page / dark dev-tool UI / 瑞士网格排版 / 终端风 / Linear-Vercel 式暗色页面, or a promo landing page (推广页/产品官网首页) in this style — even if they just say "用那个暗色风格" or "做成 personOS 首页那样".

## When to reach for it

应用或完整复刻 Warm Terminal 暖色暗终端风格——暗色落地页/暗色 dev-tool UI/瑞士网格排版/推广页官网时使用；用户点名该风格、要复刻 personOS 式落地页、或说"用那个暗色风格"即触发。

## Common questions

- **什么时候用它？**

  用户点名该风格、要复刻 personOS 首页、或要"Linear/Vercel 式暗色+瑞士网格"推广页时。

## It's working if

- 页面呈现完整的 Warm Terminal 视觉：暖色暗底、瑞士网格排版、终端质感，与参考风格对照无缺项。
- 作为推广页/官网首页使用时信息层级清晰，暗色下可读性过关。
- 用户只说"用那个暗色风格"也能命中——触发不依赖精确点名。
