erlin-skills Architecture

AI coding workflow orchestrator — three-layer prompt-driven pipeline + BDD

Three Layers

  • resources/ — 27 SKILL.md prompt templates
  • core/ — shared utilities (agents, fs, rules, diagnostics)
  • cli/ — command-line interface (7 commands)
  • cli reads resources + depends on core

Workflow Pipeline

  • erlin-dev-standards → 通用工程纪律与验证门
  • erlin-bdd → Given-When-Then 分层测试规范
  • erlin-code-review → 架构与设计原则审查
  • erlin-product-review → 产品、UX、增长与商业评估
  • show-me → 文件树、调用树、时序图等可视化解释
  • erlin-ultrawork → 多任务 worktree 编排

Key Decisions

  • SKILL.md 而非代码 — 工作流逻辑在 prompt 模板中
  • symlink 而非 copy — 更新源即生效
  • dist/ 本地构建且被 gitignore — 运行 CLI 前需 pnpm build
  • BDD 轻量集成 — Given-When-Then 贯穿全流程
