# Warm Terminal — 文案声音（推广页叙事）

页面不只是皮，它是一场六步说服。复刻推广页时，文案槽必须按本文件的句式公式填写——布局填 `page-blueprint.md` 的内容槽，每个槽"怎么说话"看这里。

## 1. 叙事骨架：页面 = 一次完整说服

| 节 | 说服任务 | 公式 | 参考站示例（zh / en） |
| --- | --- | --- | --- |
| eyebrow | 声明品类 | 「XX 操作系统 / 一句话说清你是什么」 | 个人内容操作系统 / PERSONAL CONTENT OPERATING SYSTEM |
| h1 | 转化承诺 | 「从一条 X，到值得 Y 的 Z。」——X = 用户手里的原料，Y/Z = 用户要的成果 | 从一条素材，到值得发布的内容。/ From a source to something worth publishing. |
| hero 演示 + How | 展示机制 | 用可操作的演示和三步证明，不空谈 | 看一条素材如何变成可发布的成稿。 |
| Why | 差异化回答 | 直接回答"凭什么选你" | 一个记得住上下文的内容工作区。 |
| CTA | 行动收束 | 把行动挂到用户已有的事上，降低启动成本 | 从你已经想表达的那件事开始。 |
| footer | 一句定位 | 「为……准备的……工作区」 | 为下一件清楚的事准备的专注工作区。 |

**两个导航问题**是整个骨架的目录：`XX 怎么工作`（→ #how）回答机制，`为什么是 XX`（→ #why）回答差异化。这两个短语直接用作导航链接与章节 eyebrow 的文案。

## 2. 命名公式

- **导航/章节**：`XX 怎么工作` / `How it works`；`为什么是 XX` / `Why XX`
- **CTA 编号**：`XX / 01`（品牌名 + 斜杠 + 序号）
- **步骤名**：四字动词短语，动词开头 —— 带入信号 / 确定口吻 / 保留过程（en 用动宾：Bring the signal…）
- **主张列表**（↳ 清单）：可验证的产品行为，句式「X 始终可 Y」「X 可以反复 Z」「每一 X 都可以 W」
- **管道标签**：名词大写 + 箭头串联 `SOURCE → VOICE → DRAFT`
- **版本/状态**：`V3`、`阅读 3 分钟` —— 数字必须具象

## 3. 语气规则

1. **短陈述句，句号收尾**。全站零感叹号。
2. **禁大词**：赋能、极致、颠覆、革命、一站式不出现；机制用大白话说（"把链接、想法和属于你的表达方式放在一起"）。
3. **卖点必须可验证**：每句主张对应一个真实的产品行为（可追溯/可复用/可找回），写不出对应功能的卖点删掉。
4. **少喊话**：主语是产品和用户的事物，不是"你值得拥有"式的推销腔。
5. **对比竞品但不点名**：Why 节说"大多数工具只关心下一次回答，我们关心回答周围的工作"——用事实对比，不用贬损。
6. **中文先写**：中文按自然短句写（参考站中文不是英文直译腔），再回译成同样短的英文；英文标题同样用 `text-wrap: balance` 的断行检验节奏。
7. **demo 文案 = 旁白**：状态行像操作旁白（"素材已带入。"），每步一句、句号收尾，不解释功能细节。

## 4. 逐槽速查

| 槽 | 句式 | 反例（禁止） |
| --- | --- | --- |
| h1 | 从 X，到 Y。 | 一站式智能内容创作平台！ |
| intro | 把 A、B 和 C 放在一起，生成 D，也保留 E。 | 强大的 AI 驱动解决方案 |
| proof | 为 A、B 和 C 的人准备。 | 服务于全球数百万用户 |
| 三步 | 动词短语 + 一句机制白描 | 智能化 / 自动化 / 高效化 |
| 主张 | X 可验证行为 | 最佳体验 |
| CTA 标题 | 从你已经 X 的那件事开始。 | 立即加入，开启旅程 |

## 5. 文案自查

1. 朗读测试：每句念出来像人对人说话，不像发布会 PPT；
2. 两个问题都答了：怎么工作（演示 + 三步）、为什么是（差异化）；
3. 每条主张能指出对应功能；指出对应功能的删掉；
4. 全文搜索：感叹号 0 个、"极致/赋能/一站式" 0 个；
5. 中英互换后信息量一致，英文不是中文的逐字翻译。
