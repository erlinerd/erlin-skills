# 目标

把设计稿、截图、物料目录一键变成同一 Wi-Fi 下手机/平板可看的网页画廊。核心是 `scripts/serve_lan.mjs`（Node 内置模块，无第三方依赖；图片尺寸标注走 macOS 自带 sips，缺失则只显示文件名）。

# 执行步骤

1. **想清楚给人看什么**：只服务目标目录（如 `.scratch/social/out/`）。
2. **起服务 / 查列表 / 停服务**：

   ```sh
   node ~/.agents/skills/erlin-web-lan-preview/scripts/serve_lan.mjs <目录> [--port 8765]
   node ~/.agents/skills/erlin-web-lan-preview/scripts/serve_lan.mjs --list
   node ~/.agents/skills/erlin-web-lan-preview/scripts/serve_lan.mjs --stop <port|all>
   ```

3. **报 URL**：输出即 URL：`已启动: http://<本机局域网IP>:<端口>`，直接给用户，手机同 Wi-Fi 打开即可。报 URL 用输出的完整地址，不猜 IP；`--list` 可随时查。
4. **用完关掉**：交付看图环节结束就 `--stop <port>`，避免常驻端口堆积。

服务行为（起服务后自动具备）：

- **画廊首页动态生成**：每次刷新重新扫描目录（含子目录），新增图片即时可见。
- **闲置自动关闭**：默认 10 分钟无任何请求自动退出（`--idle <分钟>` 可调，0.1 即 6 秒），端口不常占；注册表记录由 `--list` 自动清理。
- **端口自动避让**：默认 8765，被占自动 +1；进程脱离会话常驻，命令退出后服务不挂。
- **注册表**：`~/.lan-serve/servers.json` 记录端口 → 目录/pid/启动时间；`--list` 会清掉已死进程的记录。
- **支持格式**：png / jpg / jpeg / webp / gif。
- 跑长任务时（如后台截图脚本）：起服务后正常继续，不必等它。

# 判断规则

- **触发**：用户提到"局域网看图""手机看图""LAN 预览""开个服务看""serve images""物料预览""二维码看图"即使用——即使没提 skill 名。
- **目录选择**：画廊会递归列出子目录所有图片，所以只服务目标目录，不要 `~` 或项目根。
- **换目录重开**：同一个端口上起新目录前先 `--stop` 旧服务，或让脚本自动 +1 换端口（此时给用户新 URL）。
- **防火墙拦了**：症状是手机超时、本机 `curl 127.0.0.1:<port>` 正常——去 系统设置 → 网络 → 防火墙 放行 node，或重起服务触发授权弹窗。
- **图片改了不生效**：画廊每次刷新重扫，浏览器端按 Cmd/Ctrl+R 强制刷新即可；无需重启服务。
- **首次启动弹窗**：macOS 可能弹"允许 node 接受传入连接"——选允许，否则手机打不开。

# 输出格式

- 命令输出即 URL 一行：`已启动: http://<本机局域网IP>:<端口>`。
- 画廊首页：按子目录分组（手风琴展开，默认展开第一组），文件名 + 尺寸标注（sips，缺失则只显示文件名），点击放大（lightbox）；页头显示实际路径（复制按钮）+ 在 Mac 上打开（Finder）。

# 示例

## 用户问题

"宣传图放在 `.scratch/social/out/` 了，起个服务我用手机看看。"

## 工具返回

### serve_lan.mjs

`node ~/.agents/skills/erlin-web-lan-preview/scripts/serve_lan.mjs .scratch/social/out/` 输出 `已启动: http://<本机局域网IP>:8765`，进程常驻；画廊首页按子目录分组列出图片并标注尺寸。默认 10 分钟无请求自动退出；`--stop 8765` 即刻关闭并清理注册表记录。

## 最终输出

一个常驻的局域网画廊服务 + 报给用户的完整 URL；手机同 Wi-Fi 打开即可看图；交付看图环节结束后 `--stop` 关闭。

# 门禁

- 只服务目标目录；禁止服务 `~` 或项目根（画廊会递归列出子目录所有图片）。
- 报 URL 必须用脚本输出的完整地址，不猜 IP。
- 交付看图环节结束必须 `--stop <port>`，避免常驻端口堆积。
- 首次启动的"允许 node 接受传入连接"弹窗必须选允许，否则手机打不开。
