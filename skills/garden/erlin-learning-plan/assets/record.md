# <项目名> 学习记录

## 使用规则

每推进一篇，复制一份下面的「篇章记录模板」追加到「学习日志」。

先记录自己的判断，再阅读推荐答案；不要用推荐答案替代材料证据。源码事实写文件路径和函数名；文档事实写文档路径、标题和版本；自己的推论单独标注。

命令与结果必须真实：执行的命令照原样贴，附退出码；没跑的写「待执行」；失败贴原始报错。贴出原始输出前，脱敏 token、secret、私钥、个人信息和生产连接串。
