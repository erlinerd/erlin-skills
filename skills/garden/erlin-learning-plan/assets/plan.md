## 使用方式

开工前先读一遍首页的「材料地图」和「源码目录树 / 文档阅读路径」，把材料之间的关系立起来，再逐篇深入。

每篇单独推进：

1. 先读篇首的「本篇导览」（带你做什么 / 走读路线 / 带着读的疑问），再填「我的预判」。
2. 按阅读顺序打开指定源码、文档和符号，记录证据。
3. 用调用链、数据结构、概念图或论证结构表达读到的结论。
4. 回答思考题，再查看推荐答案，标出被纠正的地方。
5. 完成实践产出和验收标准。
6. 在「<项目名> 学习记录」（02-record.md）写入实际用时、检查方式、退出码或人工检查结果和下次行动。
